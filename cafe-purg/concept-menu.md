## Time & space (the dwell-time answer)
*Research warning taken seriously: board-game cafés die of "full room, no spend." So the room itself is priced, gently:*
| Item | Price |
|---|---|
| Game library access (200+ games) | $5/person evening cover (waived for members) |
| Study hall day pass (wifi + bottomless drip), Mon–Thu | $8 |
| Back-room booking (The Study, up to 10) | $25/hr, members $15 |
| Event-night cover (open mic, trivia, watch parties) | $5–15 |

### Per-head math this menu is built for
Average evening visit target: drink ($6–10) + dessert or snack ($6–12) + cover ($5) ≈ **$15–22/head** — versus the $8–10 coffee-only ticket that sinks long-dwell venues. Daytime target stays a normal $8–10.
